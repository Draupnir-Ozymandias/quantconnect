## Offline integration and missed slots

`recorder_absolute_observer` supplies explicit preparation/consume wrappers around
the isolated completion recorder. A separate exclusive control binds the new
declaration to the original case hash. The consume wrapper refuses changed
controls/sources before invoking the recorder. The original worker's optional
resource-observer argument leaves legacy callers on their original implementation.
The WebSocket receive path, segmented writer, completion witnesses, producer
pacing, public collectors and original declaration sources remain unchanged.
No global monkeypatch, signal-handler change, retry or relative-wait fallback.

The new observer runs in the recorder's existing process/unit, so its clock,
adapter, hashing, CPU/RSS reads and retained wait rows count toward recorder cost.
Pre-boundary reads retain the existing CPU-only reader mode; RSS is read only at
the integer-second endpoints. No extra memory sampler is added.
It converts the shared epoch's exact represented seconds to ceiling integer
nanoseconds once, then uses epoch_ns + slot * 1,000,000,000. It never reanchors
the epoch. Each integer-second RSS endpoint has one absolute wait. Each slot
divisible by 60 additionally has a pre-boundary endpoint 50 ms before that slot,
matching the retained counter prototype's lead. This explicitly replaces the
legacy observer's 2-ms lead; neither the 5-ms read bracket nor 50-ms wake/RSS
lateness budget is relaxed. Inclusive reads retain their actual brackets.

An already past/equal endpoint is unknown, with no syscall or resource read.
A wait returning more than 50 ms late similarly performs no resource read.
Later original slots continue; no catch-up, deadline shift, baseline subtraction,
interpolation or replacement. A missed CPU pre-read does not suppress an otherwise
qualified later RSS endpoint. A qualified wait is checked again before reading;
if that checkpoint misses its deadline, no read occurs. A pre-read cannot start
at/after its CPU boundary. Actual reads crossing boundaries or exceeding bracket
budgets remain retained and cannot pass the unchanged evaluator.
Reader brackets retain represented seconds; cross-read chronology uses that
representation rather than inventing nanosecond precision. The conservative CPU
delta includes the extra pre-boundary lead and still divides by exactly 60 seconds
times the effective quota, with no subtraction or enclosure-duration adjustment.

EINTR, another wait errno, early return, invalid wait evidence, clock regression
or an exposed wait/clock exception stops observation with its existing prefix and
explicit unavailable later slots. KeyboardInterrupt is retained without changing
handlers or resubmitting a wait and stops the observer, including during a read.
Other read errors retain their unknown slot and proceed
to later original slots without a read retry. A process kill can lose unpublished
in-memory tails; absent bytes are unknown, not a successful partial run.

Capacity remains 184 slots (at most four pre-boundary endpoints plus 184 RSS
endpoints). Reaching capacity without a stop is overflow/failure. As in the legacy
observer, stop is checked after each scheduled slot. A capture-close/read race
can leave final coverage unknown; the evaluator independently requires every
slot through the ceiling of capture/close, without inventing a tail sample. No
native wait exceeds 60 seconds. The resource payload records original float and
integer targets, exact wait receipts, separate pre-read errors, actual samples
and false origin/acceptance/order flags. The new resource auditor checks these
bindings before applying the unchanged resource gates. Existing legacy auditors
alone cannot establish acceptance of this new path.

Offline functional coverage combines the new consume wrapper, real localhost
WebSocket, segmented recorder and completion verifier for 68 burst-delivered
strings. Absolute syscalls, resource clocks/readers and Linux case context are
injected; native resource origins and budget timing are not tested. This is not
the declared 68-at-1-Hz native compatibility run and cannot populate that gate.
